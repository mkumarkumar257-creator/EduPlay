Learning goal Observe how foreground CPU work, concurrent processes, available RAM, and background tasks combine to affect a system. Change one control at a time to identify a bottleneck.

How the estimates are calculated

CPU demand = foreground workload + 35% of background workload + 1.6 points for each process above four. Utilization is capped at 100%; the system load index shows demand relative to modeled capacity.

Memory demand = processes × (0.25 GB + workload ratio × 0.20 GB) + background ratio × 2.5 GB. Memory utilization compares that demand with the selected RAM allocation.

Performance score combines CPU pressure (45%), memory pressure (35%), and process contention (20%). Estimated response time starts at 120 ms and increases with those pressures.
